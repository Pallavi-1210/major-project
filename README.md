StayEase – Rental Property Listing Platform

Overview
StayEase is a full-stack web application that allows users to explore and manage rental property listings. It includes secure authentication and authorization so users can create, update, and manage only their own listings and reviews.

Purpose
This project simplifies rental property browsing and management by providing a structured and user-friendly platform with secure access and location-based features.

Features

* Browse rental property listings
* User authentication (Sign up / Login)
* Add, edit, and delete listings (CRUD operations)
* Add and manage reviews
* Authorization (users can modify only their own data)
* Interactive maps for property locations

Tech Stack
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: Node.js, Express.js
Database: MongoDB Atlas
Maps & API: Leaflet, OpenCage API
Deployment: Render

Links
Live Demo: https://major-project-2-1mus.onrender.com/

Usage

* Users can browse listings without logging in
* Sign up/login to add listings and reviews
* Users can edit or delete only their own listings and reviews
